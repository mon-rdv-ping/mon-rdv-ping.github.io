# Mon RDV Ping

Application Android gratuite, indépendante et non officielle, pour les joueurs, capitaines et supporters du championnat par équipes de tennis de table. Sans compte, sans serveur, sans publicité.

- Informations, politique de confidentialité et mentions légales : https://mon-rdv-ping.github.io/
- Signaler un problème ou proposer une idée : onglet **Issues** (ne jamais y écrire de numéro de licence ni de nom de joueur).
- Notes de version : onglet **Releases** et fichier CHANGELOG.md.
- Demande personnelle : monrdvping@outlook.fr

Ce dépôt contient seulement la page web publique, le fichier de configuration lu par l'application (config.json : arrêt à distance et version minimale), les notes de version et le suivi des tickets. Le code de l'application est dans un dépôt privé.
